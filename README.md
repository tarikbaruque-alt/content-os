# content-os

Plataforma de inteligência e automação para estratégia, planejamento e criação de conteúdo com agentes de IA.

## Módulos

- **[Creative Studio](./creative-studio/)** — camada de **criação** de conteúdo, organizada em competências especializadas.
  - **[Reels Script Intelligence](./creative-studio/reels-script-intelligence/)** — roteiros de Reels e vídeos curtos de alto valor.

## Camadas de IA

- **Claude (LLM)** — geração criativa e raciocínio (roteiros, copy, estratégia).
- **Jev (TypeSafe, System One)** — decisão e classificação tipada (avaliação, roteamento, priorização). Configurado via credencial `TYPESAFE_API_KEY` no ambiente.
