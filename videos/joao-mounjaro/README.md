# João · Mounjaro — o que acontece quando você para (Reels 9:16, paleta verde)

Edição em Remotion, com cerca de 1 min 46 s.

## Decupagem (`scripts/montar.py`)
- Os 5 takes entram na ordem.
- Silêncios e respiros saem; as pausas internas ≥ 0,2 s viram cerca de 0,14 s, sem acelerar a voz.
- Um pequeno ajuste de enquadramento a cada corte disfarça os jump cuts.

## Layout
- **Tela dividida sem divisória:** o painel de cima dissolve-se, com desfoque, sobre o vídeo do João.
- **Cenas em tela cheia** para os momentos explicativos.
