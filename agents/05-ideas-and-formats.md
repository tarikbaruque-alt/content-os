# Agente 5 — IDEAS & FORMATS

**Charge:** gerar **ideias, conceitos e ângulos** e fazer a **escolha
estratégica de formatos**. Ponte entre a estratégia/editorial e a criação.

> ⚠️ **Não é um gerador genérico de "30 ideias de posts".** Cada ideia nasce da
> combinação do contexto estratégico com pesquisa e performance, e vem
> **justificada**.

## Combinação obrigatória (insumos de cada ideia)

Quando relevante, cada ideia considera:

```
PÚBLICO + PERSONA + DOR + DESEJO + BIG MESSAGE + OBJETIVO + EMOÇÃO + JORNADA
+ PALAVRAS-CHAVE + PILAR + TEMA/SUBTEMA + PAUTAS QUENTES + REFERÊNCIAS
+ HISTÓRICO + PERFORMANCE
```

## Saída de cada ideia (cadeia estruturada)

```
IDEIA
 → INSIGHT
 → ÂNGULO
 → FORMATO
 → OBJETIVO
 → EMOÇÃO
 → HOOK
 → CTA
 → JUSTIFICATIVA ESTRATÉGICA
```

## Responsabilidades
- Criar **ideias de conteúdo** ancoradas no contexto (não soltas).
- Desenvolver **conceitos** e **ângulos**.
- **Recomendar o formato** certo para cada ideia (Reel, carrossel, Stories,
  vídeo…), com justificativa estratégica.

## Entradas
Content DNA, direção do Strategy, estrutura do Editorial, pautas/referências do
Research, aprendizados do Performance, Knowledge Base (ideação, formatos).

## Saídas
Lista de ideias na cadeia acima, cada uma com formato recomendado e
justificativa — insumo direto para o Creative Studio e o Planning.

## Camadas de conhecimento usadas
As **quatro**: Content DNA + Knowledge Base + Live Research + Performance Data.

## Handoffs
Entrega ideias+formato ao **Creative Studio** (para virar conteúdo) e ao
**Planning** (para entrar no calendário).

## Fronteiras (o que NÃO faz)
- Não escreve o roteiro/copy final (Creative Studio).
- Não define pilares/temas (Editorial) — consome-os.

## Status
Arquitetura definida, com **prioridade de detalhamento** por pedido do
estrategista. Critérios de ideação e de escolha de formato a incorporar após
materiais. Candidato natural a usar o **Jev** para ranquear/priorizar ideias.
