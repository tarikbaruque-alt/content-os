# As 4 camadas de conhecimento

Os agentes decidem combinando **quatro fontes distintas**. Manter as fronteiras
claras é o que evita que o sistema misture "o que é verdade sobre este cliente"
com "o que é boa prática de mercado" com "o que está acontecendo agora".

| # | Camada | O que é | Específico do cliente? | Muda com o tempo? | Dono |
|---|--------|---------|:---:|:---:|---|
| 1 | **Content DNA** | Conhecimento sobre **cada cliente** | ✅ | evolui | Intelligence |
| 2 | **Knowledge Base** | Conhecimento **profissional** (estratégia, copy, persuasão, formatos, comportamento…) | ❌ | cresce | Knowledge |
| 3 | **Live Research** | Informação **externa e atual** (tendências, pautas quentes, notícias, palavras-chave, referências) | contexto | tempo real | Research |
| 4 | **Performance Data** | **Resultados reais** dos conteúdos dos clientes | ✅ | contínuo | Performance |

---

## O modelo de combinação

Uma recomendação forte quase nunca vem de uma camada só. A fórmula-guia:

```
KNOWLEDGE BASE      (o que a boa prática ensina)
   +
CONTENT DNA         (o que é verdade sobre este cliente)
   +
LIVE RESEARCH       (o que está quente agora)
   +
PERFORMANCE DATA    (o que já funcionou com este cliente)
   =
RECOMENDAÇÃO CONTEXTUALIZADA
```

Os agentes combinam **as camadas apropriadas** para cada tarefa — nem toda
tarefa usa as quatro. Exemplos:

- *"Sugira 5 ângulos para o pilar X"* → Knowledge Base + Content DNA + Live Research
- *"Este roteiro está alinhado ao cliente?"* → Content DNA + Knowledge Base
- *"O que ajustar no próximo ciclo?"* → Performance Data + Content DNA + Knowledge Base

---

## Regras de fronteira

- Um insight de **Live Research** só vira **Content DNA** se aprovado (não é fato do cliente por padrão).
- Um princípio da **Knowledge Base** é **genérico**; sua aplicação a um cliente passa pelo Content DNA.
- **Performance Data** alimenta hipóteses e aprendizados — que, aprovados, entram no Content DNA.
- Nada de **Knowledge Base** reproduz material protegido: é conhecimento **transformado** (ver [`knowledge-ingestion.md`](./knowledge-ingestion.md)).
