# Modelo de Conteúdo & Calendário

> Diretriz de **Planejamento (Cronos)**. O calendário é uma **camada central**
> do Content OS, não um acessório: é onde estratégia vira operação e volta como
> aprendizado.

---

## 1. O ciclo

```
Estratégia → Ideia → Produção → Aprovação → Publicação → Performance
                                                            │
                        ◀───────── aprendizado ─────────────┘
```

## 2. Fluxo de status

```
IDEA → PLANNED → IN PRODUCTION → REVIEW → WAITING APPROVAL → APPROVED → SCHEDULED → PUBLISHED
```

---

## 3. O registro de conteúdo (modelo de dados)

Cada peça pode carregar:

**Identificação & operação**
`cliente` · `data` · `plataforma` · `responsável` · `status` · `aprovação` · `observações`

**Contexto estratégico**
`objetivo` · `jornada` · `funil` · `função estratégica` · `pilar` · `tema` ·
`subtema` · `tópico` · `ideia` · `ângulo` · `formato` *(superfície + formato criativo)*

**Conteúdo produzido**
`headline/hook` · `roteiro` · `copy` · `CTA`

**Camada criativa (rastreabilidade da decisão)**
`gatilhos/princípios persuasivos utilizados` · `elementos literários/narrativos utilizados` · `direção visual`

> ⚠️ **Modelo de dados ≠ interface.** Todos esses campos existem no modelo; a
> interface mostra **apenas o que é útil naquele momento**. O usuário não deve
> encarar um formulário de 25 campos. O contexto estratégico completo aparece
> ao **abrir um conteúdo**, não na listagem.

## 5. Geração de calendário por IA (futuro)

Pedido-alvo: *"Crie um calendário editorial estratégico de 30 dias para o Cliente X."*

O sistema executa uma **cadeia de decisões**, não uma lista aleatória:

```
1. consultar Content DNA
2. consultar estratégia (Átlas)
3. recuperar Knowledge Base relevante (Acervo)
4. pesquisar quando necessário (Radar)
5. definir distribuição editorial (Bússola)
6. selecionar objetivos / jornada / funil / função estratégica
7. gerar ideias (Musa)
8. escolher formatos (superfície + formato criativo)
9. criar conteúdos (Rima)
10. gerar headline / copy / roteiro / CTA
11. organizar no calendário (Cronos)
12. apresentar para revisão humana
```

> **Critério de qualidade:** não são 30 ideias distribuídas em datas. São **30
> decisões editoriais conectadas a uma estratégia** — cada uma com razão de
> existir, função estratégica e lugar na cadeia editorial.

O resultado **sempre** passa por revisão humana antes de virar plano.
